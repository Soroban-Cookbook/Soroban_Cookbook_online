Real-World Examples​

Gas Optimization

Use Temporary storage for ephemeral data to reduce gas costs in your Soroban contracts.

Security Warning

Never store private keys or sensitive credentials in contract storage. All data is publicly visible on the blockchain.

Best Practice

Always implement proper authorization checks using Soroban's built-in require_auth function.

Usage​

import { Callout } from '@site/src/components/Callout';

<Callout variant="tip">
  Your helpful tip here
</Callout>

<Callout variant="warning" title="Custom Title">
  Important warning message
</Callout>
