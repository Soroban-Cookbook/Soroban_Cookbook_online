Empty States

Empty states appear when there's no content to display — a search returns nothing, a pattern list is empty, or a section hasn't been populated yet. A good empty state reduces confusion by explaining why content is missing and offering a clear next step.

Anatomy​

Every empty state is built from four optional slots:

SlotRequiredPurpose
iconNoVisual anchor — emoji or SVG
titleYesShort, plain-language heading
bodyNoOne sentence explaining the situation and what to do
actionsNoOne or two CTAs — primary action first

Sizes​

Three sizes to match the surrounding context.

Small — inline / sidebar​

📭

Nothing here yet

Content will appear once it's available.

<EmptyState
  size="sm"
  icon="📭"
  title="Nothing here yet"
  body="Content will appear once it's available."
/>

Medium (default) — content area​

🔍

No results found

Try a different search term or browse all patterns.

Browse patternsClear search
<EmptyState
  icon="🔍"
  title="No results found"
  body="Try a different search term or browse all patterns."
  actions={[
    { label: 'Browse patterns', href: '/docs/patterns/overview' },
    { label: 'Clear search', variant: 'secondary', href: '#' },
  ]}
/>

Large — full-page / hero​

🧩

No patterns available

This category doesn't have any patterns yet. Check back soon or contribute one.

Scenario: Search — No Results​

Use when a search query returns zero matches.

🔍

No results for "timelock"

Double-check your spelling, or try broader terms like "escrow" or "token".

Browse all patternsClear search
// Typically rendered inside your search results component
{
  results.length === 0 && (
    <EmptyState
      icon="🔍"
      title={`No results for "${query}"`}
      body='Double-check your spelling, or try broader terms like "escrow" or "token".'
      actions={[
        { label: 'Browse all patterns', href: '/docs/patterns/overview' },
        { label: 'Clear search', variant: 'secondary', onClick: clearSearch },
      ]}
    />
  );
}

Scenario: Pattern Category — Empty​

Use when a pattern category exists but has no entries yet.

🧩

No DeFi patterns yet

We're working on it. In the meantime, explore token standards or contribute a pattern.

Contribute a patternContribute a patternView token patterns
{
  patterns.length === 0 && (
    <EmptyState
      icon="🧩"
      title={`No ${category} patterns yet`}
      body="We're working on it. In the meantime, explore token standards or contribute a pattern."
      actions={[
        { label: 'Contribute a pattern', href: '/contributing' },
        { label: 'View token patterns', variant: 'secondary', href: '/docs/patterns/overview' },
      ]}
    />
  );
}

Writing Guidelines​

Title — state the situation plainly. Avoid "Oops" or "Uh oh".

✅ Do❌ Don't
"No results found""Oops! Nothing here."
"No DeFi patterns yet""This section is empty."
"Nothing matches your search""Error: no data."

Body — one sentence. Explain why and what to do next.

Actions — maximum two. Primary action first, secondary (or ghost) second.

Props​

PropTypeDefaultDescription
titlestring—Required. Short heading.
iconReactNode—Emoji, SVG, or component.
bodyReactNode—Supporting copy.
actionsEmptyStateAction[][]CTA buttons.
size'sm' | 'md' | 'lg''md'Size variant.
classNamestring—Extra CSS class.
