# SAC Client Example

This example demonstrates how to interact with the Stellar Asset Contract (SAC) in Soroban.

> **Note:** The Stellar Asset Contract is the production token path for Soroban. When building applications that transfer native tokens or classic assets (like USDC), you should use the SAC rather than a custom token contract.

## Features

- Transfer tokens via SAC.
- Mint tokens (Stellar Asset Contract administrator functionality).
- Check balances.

## Usage

```bash
cargo test
```
