Tu guía completa para construir contratos inteligentes en Stellar.

## 🚀 ¿Qué es Soroban?

Soroban es la plataforma de contratos inteligentes de Stellar que permite a los desarrolladores escribir e implementar contratos inteligentes usando Rust. Diseñado para escalabilidad, seguridad y experiencia del desarrollador.

## 📚 ¿Qué aprenderás?

Construye contratos inteligentes listos para producción en Soroban, desde conceptos básicos hasta patrones avanzados:

- **Configuración del entorno** - Prepara tu entorno de desarrollo
- **Conceptos fundamentales** - Entiende la arquitectura y los patrones de Soroban
- **Contratos inteligentes** - Construye ejemplos de contratos del mundo real
- **Mejores prácticas** - Aprende técnicas de seguridad y optimización

## ✨ Características de Soroban

- ⚡ **Finalidad en menos de un segundo** - Confirmación rápida de transacciones
- 💰 **Costos bajos** - Tarifas de transacción mínimas
- 🔒 **Seguro** - Construido con la seguridad de memoria de Rust
- 🦀 **Impulsado por Rust** - Aprovecha el ecosistema de Rust
- 🌐 **Red Stellar** - Acceso a infraestructura financiera global
