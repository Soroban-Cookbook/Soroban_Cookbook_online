Seu guia completo para construir contratos inteligentes na Stellar.

## 🚀 O que é Soroban?

Soroban é a plataforma de contratos inteligentes da Stellar que permite aos desenvolvedores escrever e implantar contratos inteligentes usando Rust. Desenvolvido para escalabilidade, segurança e experiência do desenvolvedor.

## 📚 O que você vai aprender?

Construa contratos inteligentes prontos para produção no Soroban, dos conceitos básicos aos padrões avançados:

- **Configuração do ambiente** - Prepare seu ambiente de desenvolvimento
- **Conceitos principais** - Entenda a arquitetura e os padrões do Soroban
- **Contratos inteligentes** - Crie exemplos de contratos do mundo real
- **Melhores práticas** - Aprenda técnicas de segurança e otimização

## ✨ Recursos do Soroban

- ⚡ **Finalidade em menos de um segundo** - Confirmação rápida de transações
- 💰 **Baixo custo** - Taxas de transação mínimas
- 🔒 **Seguro** - Construído com a segurança de memória do Rust
- 🦀 **Powered by Rust** - Aproveite o ecossistema Rust
- 🌐 **Rede Stellar** - Acesso à infraestrutura financeira global
