Migration guides document what changed between documentation versions so you can upgrade your
contracts and tooling confidently when you move to a newer `soroban-sdk` release. Each guide
covers breaking changes, renamed APIs, and recommended upgrade steps for one version transition.

See [Versioning Strategy](/docs/contributing/versioning-strategy) for how and when new
documentation versions (and their migration guides) are cut.

## Available guides

- [Baseline: docs versioning starts at 22.0](./baseline-22-0.md) — what "version 22.0" of these
  docs represents and where to start if you're new to the versioned docs.

Don't see a guide for the SDK versions you're migrating between? [Open an issue](https://github.com/Soroban-Cookbook/Soroban_Cookbook_online/issues)
or contribute one using the [migration guide template](./template.md).
