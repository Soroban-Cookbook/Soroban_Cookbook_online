# Alerts & Callouts

Standardized components for displaying important information with visual emphasis throughout the documentation.

## Overview

<Callout variant="info">
  Alert and Callout components are automatically available in all MDX files without importing.
</Callout>

### Alert vs Callout

- **Alert**: Interactive notifications for user feedback, system messages, and dismissible content
- **Callout**: Static emphasis blocks for documentation content, tips, and important notes

## Alert Component

### Variants

<Alert variant="info" title="Info">
  Use for general information, notices, and helpful context.
</Alert>

<Alert variant="warning" title="Warning">
  Use for cautions, deprecations, and actions requiring attention.
</Alert>

<Alert variant="error" title="Error">
  Use for errors, failures, and critical issues.
</Alert>

<Alert variant="success" title="Success">
  Use for confirmations, successful operations, and positive outcomes.
</Alert>

### Usage Examples

```mdx
<Alert variant="info">
  Basic informational message.
</Alert>

<Alert variant="warning" title="Important">
  Warning with a title.
</Alert>

<Alert variant="error" icon={false}>
  Error without an icon.
</Alert>
```

## API Reference

### Alert Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'info' \| 'warning' \| 'error' \| 'success'` | `'info'` | Visual style |
| `display` | `'block' \| 'inline'` | `'block'` | Display mode |
| `title` | `string` | - | Optional title |
| `icon` | `ReactNode \| boolean` | `true` | Icon display |
| `onClose` | `() => void` | - | Close handler |
| `className` | `string` | - | Additional classes |

### Callout Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'info' \| 'warning' \| 'error' \| 'success' \| 'tip'` | `'info'` | Visual style |
| `display` | `'block' \| 'inline'` | `'block'` | Display mode |
| `title` | `string` | - | Optional title |
| `icon` | `ReactNode \| boolean` | `true` | Icon display |
| `className` | `string` | - | Additional classes |
